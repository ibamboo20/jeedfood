# 🍳 JeedFood — แอปเมนูอาหารสุขภาพสำหรับเด็ก 7 ขวบ

แอปหน้าเว็บล้วน ๆ (HTML + CSS + JavaScript) ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต

**เปิดใช้งานออนไลน์ได้ที่ 👉 https://ibamboo20.github.io/jeedfood/**

## วิธีเปิดใช้งาน

ดับเบิลคลิกไฟล์ `index.html` ได้เลย

ถ้าอยากเปิดผ่านเซิร์ฟเวอร์ (เช่น อยากเปิดจากมือถือในวง Wi-Fi เดียวกัน):

```bash
python3 -m http.server 4173
```

แล้วเปิด http://localhost:4173

## หน้าจอในแอป

| หน้า | ทำอะไร |
|---|---|
| **หน้าหลัก** | แสดงเมนูประจำวัน แยกเป็นแท็บ Breakfast / Lunch / Dinner มื้อละ **9 รายการ** พร้อมรูปการ์ตูน และมี **ช่องค้นหาชื่ออาหาร** จากทั้งคลัง |
| **หน้ารายละเอียด** | กดที่การ์ดเมนู → เห็นส่วนผสมทั้งหมด + ขั้นตอนการทำแบบสั้นง่าย + ประโยชน์ต่อร่างกาย |
| **หน้าตั้งค่า** (ปุ่ม ⚙️ มุมขวาบน) | ใส่วัตถุดิบหลักที่บ้านมี |
| **หน้าบันทึกเมนู** | รวมเมนูที่เลือกไว้ของวันนั้น พร้อมส่งออกเป็นรูปหรือ PDF |

## เมนูคิดมาจากอะไร

- **Breakfast** (อาหารเช้าสไตล์ฝรั่งง่าย ๆ) และ **Lunch** (กล่องข้าว หยิบทานง่าย)
  → คิดจาก **วัตถุดิบในหน้าตั้งค่า** เช่น ถ้าเลือก ไข่ + ขนมปัง + ไส้กรอก จะได้เมนูอย่าง
  FRIED EGG & TOAST, SCRAMBLED EGGS & SAUSAGE, SAUSAGE & EGG ROLL BOX, MINI SANDWICH BOX
- **Dinner** เป็นมื้อหนักเน้น **ข้าวหรือเส้น** ที่มีสารอาหารครบสำหรับเด็ก ไม่ขึ้นกับหน้าตั้งค่า
  โดย 50 เมนูเป็น **อาหารไทยที่ไม่เผ็ด** (ข้าวไข่เจียวหมูสับ, ผัดไทยกุ้ง, ข้าวไก่ผัดขิง, แกงจืดตำลึง,
  ต้มข่าไก่ไม่เผ็ด, ข้าวกะเพราไก่ไม่ใส่พริก ฯลฯ)
- ถ้าวัตถุดิบที่มียังทำได้ไม่ถึง 9 เมนู แอปจะเติมเมนูที่ **ขาดของน้อยที่สุด** พร้อมป้าย `ขาด …` บอกว่าต้องซื้ออะไรเพิ่ม

## ค้นหาชื่ออาหาร (หน้าหลัก)

ช่องค้นหาบนหน้าหลักค้นจาก **ทั้ง 232 เมนูในคลัง** ไม่ใช่แค่ 9 เมนูของวันนี้

- พิมพ์ได้ทั้งไทยและอังกฤษ เช่น `ผัดไทย`, `ข้าวต้ม`, `toast`, `soup`
- ผลลัพธ์รวมทุกมื้อไว้ด้วยกัน แต่ละใบมีป้ายบอกว่าเป็นมื้อไหน (🌅 เช้า / 🎒 กลางวัน / 🌙 เย็น)
- ยังมีป้าย `ขาด …` บอกว่าต้องซื้ออะไรเพิ่มเหมือนเดิม
- ระหว่างค้นหาแท็บมื้ออาหารจะถูกซ่อน กดปุ่มล้างเพื่อกลับไปดูเมนูประจำวัน
- แสดงสูงสุด 48 รายการต่อการค้นหนึ่งครั้ง (ปรับที่ `SEARCH_LIMIT` ใน `js/app.js`)

## เลือกวันที่เพื่อวางแผนล่วงหน้า

แถบวันที่บนหน้าหลักเลือกได้ว่าจะดูเมนูของวันไหน

- ปุ่ม **‹ ›** เลื่อนทีละวัน หรือแตะช่องวันที่เพื่อเปิดปฏิทินเลือกวันไหนก็ได้
- มีป้ายบอกระยะ เช่น *วันนี้ / พรุ่งนี้ / มะรืนนี้ / อีก 5 วัน / เมื่อวาน* และปุ่ม **↩︎ วันนี้** เมื่อออกจากวันปัจจุบัน
- เมนูประจำวันสุ่มจาก "วันที่ที่เลือก" เปิดดูวันไหนกี่ครั้งก็ได้เมนูชุดเดิมของวันนั้นเสมอ
  และภายในสัปดาห์เดียวกันมีเมนูซ้ำได้
- ปุ่ม 🎲 สุ่มใหม่ มีผลเฉพาะวันที่กำลังดูอยู่

## เลือกเมนูแล้วบันทึกเก็บไว้

เลือกได้ **มื้อละ 1 เมนู** (เช้า / กลางวัน / เย็น) จะเลือกไม่ครบทุกมื้อก็ได้
และ **แผนของแต่ละวันแยกกัน** จึงวางแผนล่วงหน้าหลายวันได้

- กดปุ่ม **＋** ที่มุมขวาบนของรูปอาหารในหน้าหลัก หรือปุ่ม **＋ เลือกเมนูนี้** ในหน้ารายละเอียด
- เลือกเมนูใหม่ในมื้อเดิมจะแทนที่ของเดิมอัตโนมัติ กดซ้ำที่เมนูเดิมคือเอาออก
- เมนูที่เลือกไว้จะมีขอบสีชมพูและเครื่องหมาย ✓ และมีแถบสรุปด้านบนบอกว่าเลือกแล้วกี่มื้อ
- แผนของแต่ละวันถูกจำไว้ในเครื่อง (`jeedfood.plans.v1`) เปิดใหม่ก็ยังอยู่

กดแถบสรุปเพื่อไปหน้าบันทึก ซึ่งรวมเมนูที่เลือกไว้ **ของวันนั้น** พร้อม **ส่วนผสมและวิธีทำเต็ม** แล้วบันทึกได้ 2 แบบ
(ไฟล์ที่ได้จะมีวันที่กำกับ และตั้งชื่อไฟล์ตามวัน เช่น `jeedfood-2026-08-20.png`)

| ปุ่ม | ได้อะไร |
|---|---|
| 🖼️ บันทึกเป็นรูป | ไฟล์ PNG ความละเอียด 2 เท่า วาดด้วย canvas เอง ไม่ใช้ไลบรารีภายนอก ดาวน์โหลดทันที |
| 📄 บันทึกเป็น PDF | เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ เลือกปลายทางเป็น *Save as PDF* (มี print stylesheet ซ่อนปุ่มต่าง ๆ และกันไม่ให้การ์ดถูกตัดข้ามหน้า) |

รูปอาหารในไฟล์ PNG ใช้ `drawFoodStandalone()` ซึ่งฝัง `<defs>` ของไล่เฉดสีไว้ในตัว
เพราะ SVG ที่ถูกดึงออกไปนอกหน้าเว็บจะอ้าง `url(#...)` ที่อยู่คนละที่ไม่ได้

## ชื่อภาษาอังกฤษของส่วนผสม

- **หน้าตั้งค่า** — วัตถุดิบทุกตัวมีชื่อไทยและชื่ออังกฤษกำกับใต้ไอคอน เช่น ไข่ / Egg, อโวคาโด / Avocado
- **หน้ารายละเอียดเมนู** — ทุกบรรทัดในรายการส่วนผสมมีป้ายชื่ออังกฤษต่อท้าย เช่น
  `ขนมปังโฮลวีต 1 แผ่น` → `Bread`, `ก้อนแกงกะหรี่ญี่ปุ่น 2 ก้อน` → `Japanese curry roux`
  บรรทัดที่มีหลายวัตถุดิบจะขึ้นครบ เช่น `มันฝรั่ง แครอท หอมใหญ่` → `Potato · Carrot · Onion`
- **กล่อง "ต้องซื้อเพิ่ม"** — แสดงเป็น `อโวคาโด (Avocado)`

## ชุดสี

| ตัวแปร | สี | ใช้กับ |
|---|---|---|
| `--white` | `#FEFBFB` | พื้นหลังแอปและการ์ด |
| `--mint` | `#D5EDDF` | ป้ายวันที่, เครื่องหมายถูก, พาเนลประโยชน์ |
| `--orchid` | `#E5A7E5` | หัวข้อหมวด, เลขลำดับขั้นตอน, ป้ายชื่ออังกฤษ |
| `--pink` | `#F994CF` | สีหลัก — ชื่อแอป, แท็บที่เลือก, จุดหน้าส่วนผสม |
| `--rose` | `#D49FA3` | ป้าย "ขาด …" และกล่อง "ต้องซื้อเพิ่ม" |

ตัวอักษรใช้โทนน้ำตาล `--ink: #4A342A` และ `--ink-soft: #8A6A5E`
ซึ่งเป็นสีเดียวกับเส้นขอบของรูปอาหาร ทำให้ทั้งแอปดูเป็นชุดเดียวกัน

ชื่ออังกฤษมาจาก 2 ที่คือ ฟิลด์ `en` ของวัตถุดิบใน `js/ingredients.js` และตาราง `EXTRA_EN`
สำหรับเครื่องปรุง/วัตถุดิบที่ไม่ได้อยู่ในคลังหลัก (เนย, มายองเนส, ซีอิ๊วขาว ฯลฯ)
ถ้าเพิ่มเมนูใหม่แล้วใช้วัตถุดิบที่ยังไม่มีในสองที่นี้ ให้เติมคำนั้นลงใน `EXTRA_EN`

## การตั้งค่าส่วนผสม

- แตะเลือกจากไอคอนวัตถุดิบ 86 อย่าง (โปรตีน / แป้ง / นม-ชีส / ผัก / ผลไม้) มีชื่อไทย + อังกฤษ
- มี **ช่องค้นหา** ด้านบน พิมพ์ได้ทั้งไทยและอังกฤษ เช่น `ไข่`, `egg`, `ปลา`, `cheese`
  แล้วรายการจะกรองให้ทันที หมวดที่ไม่มีผลลัพธ์จะถูกซ่อน
- เลือกหรือยกเลิกได้ระหว่างที่ยังกรองอยู่ คำค้นหาไม่หาย
- ค่าที่เลือกถูกจำไว้ในเครื่อง (localStorage) เปิดใหม่ก็ยังอยู่

## โครงสร้างไฟล์

```
index.html            หน้าเว็บหลัก
css/styles.css        สไตล์ทั้งหมด
js/ingredients.js     คลังวัตถุดิบ + ตารางชื่ออังกฤษของเครื่องปรุง
js/recipes.js         คลังเมนู 232 เมนู (เช้า 80 / กลางวัน 82 / เย็น 70)
js/food-art.js        ระบบวาดรูปอาหารการ์ตูนสไตล์ Overcooked (SVG ล้วน)
js/app.js             ตรรกะแอป: เลือกเมนูประจำวัน, หน้าจอ, การตั้งค่า
```

รูปอาหารทั้งหมดวาดด้วยโค้ด SVG ไม่ใช้ไฟล์ภาพ — แต่ละเมนูประกอบจากชิ้นส่วนอาหาร 93 ชิ้น
(ไข่ดาว, ขนมปัง, ไส้กรอก, ข้าว, เส้น ฯลฯ) วางบนฐาน 3 แบบคือ **จาน / ชาม / กล่องข้าว**

สไตล์ภาพเป็นแบบการ์ตูนน่ารัก ประกอบด้วย

- **หน้าตาน่ารักบนอาหาร** — 4 อารมณ์ (ยิ้ม / ขยิบตา / หลับตายิ้ม / อ้าปาก) สุ่มคงที่ตามเมนู
  ระบบจะเลือกวางหน้าบนอาหารชิ้นเด่นที่ **สีอ่อน** ก่อนเสมอ (ดู `FACE_ON` และ `FACE_DARK`) เพื่อให้เห็นตาชัด
- **แสงเงา** — ไล่เฉดสีทุกชิ้น (`GRADS`), เงาใต้จาน และเงาสัมผัสใต้อาหารแต่ละชิ้น
- **พื้นหลังชมพูอ่อน** เข้าชุดกับสีแอป พร้อมเกล็ดพริกไทย/ต้นหอมโรยหน้าไข่

### ชามและน้ำซุป

เมนูที่ใช้ฐาน `bowl` อาหารจะถูกวางให้ **ก้นจมลงไปในชาม** (ตัวชามวาดทับส่วนล่างของอาหาร)
ไม่ใช่ลอยอยู่เหนือปากชาม

เมนูที่เป็นน้ำซุปให้ใส่ `soup: true` ในข้อมูลเมนู แล้วผิวในชามจะเปลี่ยนจากสีครีม
เป็น **น้ำซุปสีทอง** พร้อมระลอกคลื่นและหยดน้ำมันลอย — ตอนนี้มี 20 เมนู
(ก๋วยเตี๋ยวน้ำ, แกงจืด, ต้มจืด, ข้าวต้ม, โจ๊ก, สุกี้น้ำ, ต้มข่า, บะหมี่เกี๊ยวน้ำ ฯลฯ)
ส่วนเมนูชามที่ไม่ใช่น้ำซุป เช่น ข้าวหน้าต่าง ๆ, โยเกิร์ตโบว์ล, ไข่ตุ๋น จะไม่ใส่ธงนี้

### กล่องข้าวกลางวัน (เบนโตะ)

เมนูมื้อกลางวันใช้ตัววาดแยกคือ `drawBento()` เพื่อให้ **จัดเต็มกล่อง** แบบกล่องเบนโตะจริง

- กล่องไม้ 5 ช่อง + ถ้วยซอสมุมขวาล่าง + ผักสลัดรองก้นกล่อง
- วัตถุดิบหลักจะถูกวาง **ซ้ำหลายชิ้น** (ตัวเอก 3 ชิ้น + ของเคียงอีก 2) ตามตาราง `BENTO_MIX`
- ทุกชิ้นที่วางหน้าได้จะ **มีหน้าเป็นของตัวเอง** สลับอารมณ์กันไป ไม่ใช่หน้าเดียวทั้งจาน
- ชิ้นเล็ก (ชีส, มะเขือเทศ, บลูเบอร์รี) ถูกขยายพิเศษด้วย `BENTO_BOOST` ไม่ให้กล่องดูโหวง
- ขนาดและองศาของแต่ละชิ้นสุ่มต่างกันเล็กน้อย (คงที่ตามเมนู) ให้ดูเหมือนคนจัดเอง

## อยากเพิ่มเมนูเอง

เปิด `js/recipes.js` แล้วเพิ่มออบเจกต์ตามรูปแบบนี้

```js
{
  id: 'bf31', name: 'EGG & CHEESE TOAST', th: 'ขนมปังไข่ชีส',
  needs: ['egg', 'bread', 'cheese'],   // key วัตถุดิบหลัก (ดูใน ingredients.js)
  base: 'plate',                        // plate | bowl | box
  art: ['toast', 'egg_fried', 'cheese_slice'],  // ชิ้นส่วนรูป (ดูใน food-art.js) สูงสุด 4 ชิ้น
  time: 10,
  good: 'อธิบายสั้น ๆ ว่าดีต่อร่างกายยังไง',
  ing: ['ไข่ 1 ฟอง', 'ขนมปัง 1 แผ่น', 'ชีส 1 แผ่น'],
  steps: ['ขั้นตอนที่ 1', 'ขั้นตอนที่ 2'],
}
```

เมนูเช้าใส่ไว้ในอาเรย์ `BREAKFAST` (id ขึ้นต้น `bf`), กลางวัน `LUNCH` (`ln`), เย็น `DINNER` (`dn`)
